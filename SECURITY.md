# Security policy

Folt-CLI projects are in early development. Security fixes target the current
development branch; there are no supported stable releases yet.

## Reporting a vulnerability

Report suspected vulnerabilities privately through the affected repository's
**Security** tab → **Report a vulnerability**, using GitHub private vulnerability
reporting. If that option is unavailable, email 0ivanovskibojan@gmail.com.

Include the affected repository and revision, reproduction steps, expected impact
and any suggested fix in your private report. Do not disclose credentials,
private data or vulnerability details in public issues or pull requests.

The maintainer will assess the report and coordinate a fix and disclosure with
the reporter. There is no guaranteed response or remediation time at this stage.
