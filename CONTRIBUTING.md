# Contributing

Follow the [Code of Conduct](CODE_OF_CONDUCT.md) when participating in the
Folt-CLI community.

Start by reading the repository's README and documentation. Use the
[Folt development process](https://github.com/Folt-CLI/folt/blob/develop/docs/dev/process.md)
as the reference workflow. A repository may have its own CONTRIBUTING.md;
those repository-specific guidelines take precedence over these defaults.

Open an issue before starting large changes so the scope and approach can be
discussed. Use the repository's issue forms. For defects, include reproduction
steps and impact.

Keep secrets, credentials and private data out of code, issues and pull requests.
Use placeholders when documenting configuration. Report suspected security
vulnerabilities privately using the [security policy](SECURITY.md).
