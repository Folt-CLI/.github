## What is Folt

Folt is a standalone Rust command-line tool for managing documents, called Folios,
the way Git manages source code. It works on Folios locally and exchanges them
with remotes. Foltivo is the first intended remote host, much as GitHub is for Git,
but Folt does not depend on it.

## What is a Folio

A Folio is a document that Folt manages. Its format has not been selected yet.

## Status

Folt is in early planning; nothing has been released. The Folio format, sync
protocol and command set have not been selected yet.
